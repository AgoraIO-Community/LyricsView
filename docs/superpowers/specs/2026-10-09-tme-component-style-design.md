# TME 歌词和打分组件样式统一

用户指定以音集协界面作为 TME 的显示样式基准。

两页使用同一组 XML 样式：打分组件全宽、120dp 高、橙色背景，与歌词组件间距 20dp；歌词组件全宽、200dp 高、紫色背景，内边距和基础文字属性沿用音集协。TME 页面头部及播放按钮保留，组件区域去掉外层 16dp 横向内边距。

将 MainActivity 中现有的歌词、音高及粒子外观设置提取到 KaraokeViewStyle，两页都读取 karaoke_sample_app 的相同外观偏好，包括颜色、字号、行距、换行、前奏提示及自定义音高指示器。音集协原有拖动开关仍由 MainActivity 应用；TME 保持禁止拖动，以保留当前播放和计分流程。

不修改 TME 请求、资源准备、播放器状态机或计分算法。验证构建、已有演唱页测试和实机歌曲播放后的显示效果。
