# Demo 演唱入口与底部选歌

用户已在可视化稿确认以下方案，并授权执行。

- 启动即演唱页；Service Type 仅有 TME、音集协，首次默认音集协，内部仍是 MCC_EX。旧 MCC/无效偏好迁移到 MCC_EX/KRC，TME 仍为 LRC。
- 演唱页导航栏包含选歌、设置。选歌为从底部展开的面板，高度为总体屏幕高度的 80%，沿用单行歌曲列表样式，不含设置按钮。
- 面板标题按当前服务显示 TME 选歌或音集协 选歌。TME 复用现有歌曲查询；音集协复用 asMusicListEx 配置列表。
- 选中歌曲收起面板并交给原有服务流程。关闭面板不更换歌曲，不触发播放器暂停或重建。
- 设置未更改服务时保留原歌曲与会话；TME 延续进入后台时暂停、返回后手动继续的既有行为。更改服务则结束原会话，返回对应服务的演唱页等待选歌。设置的其他行为不变。
- 删除曲库入口。解析器、XML/音集协歌词实现、评分算法和 TME 播放控制器均不修改。

MainActivity 继续持有 RTC/ServiceManager 与音集协演唱控件。TME 的现有演唱显示代码抽为 Fragment，嵌入同一主页面，保持原先 attach/detach、页面确认与计分输入顺序；TmeSingingActivity 留作现有独立页面测试的兼容宿主。共用 BottomSheetDialogFragment 只处理列表、重试与歌曲选择；由宿主开始演唱。

验证覆盖默认及旧偏好迁移、两种服务设置切换、面板标题/80% 高度/无设置按钮、关闭不改变会话、选中指定音集协歌曲、TME 首播门槛与降级等已有回归。使用本机缓存 Gradle 8.7 和现有 Android 模拟器；不以模拟回调测试宣称真实线上演唱验证。
